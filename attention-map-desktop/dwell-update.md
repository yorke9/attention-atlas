# 停留时长比例更新

新版程序：`../注意力地图-Windows版-时长比例版.exe`。

当前旧程序正在运行。先保存本次记录，再从系统托盘菜单选择“退出程序”，然后打开新版；只关闭主窗口会收起到托盘。

## 显示规则

- 停留圆的面积与时长成正比，例如 120 秒的面积是 60 秒的两倍。
- 在 24 px 范围连续停留至少 1 秒才生成圆；相近区域的重复停留累计计算。
- 长停留不会被截成同一档。时长差距很大时，所有圆统一缩放，保留彼此的面积比例。
- 达到 5 秒后标注实际秒数，如 `120 s`、`1800 s`；点击圆内的数字仍表示点击次数。
- 停留圆由“热力底图”开关控制。回放只累计当前时刻之前的停留，导出的 PNG 使用相同规则。

