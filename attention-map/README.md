# 注意力地图 / Attention Atlas

第一版：全屏交互实验。在五分钟内记录当前网页上的鼠标移动与停留，生成热力图并回放路径。

## 运行

安装 Node.js 后，在此目录运行 `npm run dev`，打开 http://127.0.0.1:4173 。没有依赖安装或构建步骤，也可以直接用浏览器打开 `dist/index.html`（浏览器可能限制 file 协议下的本地保存）。

## 已实现

- 五分钟倒计时、暂停、继续与到时自动完成。
- 鼠标经过形成连续热力路径，停留积累更深的颜色。
- 切换标签页自动暂停，离开画布、经过控件不计入停留。
- 热力与路径叠加开关、两套配色。
- 纤细的分钟分色路径、时间图例；24 px 内实际点击聚合，圆点与数字表示次数。
- 路径、热力底图和点击标记分别开关；回放与 PNG 导出采用相同绘图逻辑。
- 时间轴与 10 倍速回放；导出完整地图为 PNG。
- localStorage 自动保存，刷新后恢复为暂停状态；今日历史，最多保留 12 次。
- 归一化坐标，调整窗口尺寸后重新绘制。
- 触摸轨迹、键盘快捷键、响应式布局、减少动态效果设置。

## 数据与边界

网页只能记录当前页面。鼠标轨迹不是眼动追踪，也不是注意力的科学测量。页面不读取其他应用、不上传鼠标记录；发布后的登录访问由 Sites 负责，地图应用本身无需注册。

数据以 `attention-atlas-v1` 为键保存在当前浏览器的 localStorage；5 秒自动保存一次，暂停、关闭页面时再次保存。示例数据明确标注，永不进入历史。清除浏览器数据会清空记录。

探索面积以 40 × 24 网格中鼠标实际经过的单元格比例计算；最长停留为在半径 24 px 范围内连续停留的时间；游走距离按该次开始时的视口像素计算。五分钟以页面可见且记录运行的时间计算，暂停时间不计入。

## 文件

- `dist/index.html`：页面结构。
- `dist/styles.css`：布局与视觉。
- `dist/engine.js`：热力累积、统计与本地数据校验。
- `dist/app.js`：记录、状态切换、回放、保存与导出。
- `server.mjs`：仅本地使用的静态预览服务。
- `build-offline.mjs`：运行 `npm run build:offline`，将当前页面、样式与脚本打包到上一级的 `注意力地图-离线版.html`。

`npm test` 验证分钟交界、点击聚合、旧记录与数据校验。安装 Playwright 并具备 Edge 时，可以运行 `node tests/browser-check.cjs` 验证源码页和离线页的记录、恢复、回放、导出及手机布局。

## 后续迭代

可以依使用反馈逐步加入：日汇总、热区标注、不同记录时长、JSON 导入导出。跨网页记录需要浏览器扩展；跨应用记录需要桌面程序，不能仅靠此网页实现。
